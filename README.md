One sentence, at most 200 characters, on a small moment of wonder in everyday life: the escalator handrail moves a little faster than the steps, as if it is in more of a hurry to get home than I am.

## Run it

```sh
node main.ts
```

The program writes the sentence to `/output/entry.txt` (114 characters, one line, no trailing newline, deterministic).
